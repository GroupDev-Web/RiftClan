RIFT Clan static website

Upload all files and folders in this ZIP to your web hosting root. No build, dependencies, or backend are required.

/discord and /join use directory index pages with HTML and JavaScript redirects. Your host must support directory index.html files (standard on most static hosts). Both include a manual link fallback.

Edit index.html for homepage text and style.css for styling. rift-logo.png is the RIFT crest.
